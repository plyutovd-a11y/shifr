# Shifr

Портативная программа для Windows 11 и Alt Linux (x86_64). Она шифрует чувствительный текст
в презентации .pptx, чтобы файл можно было отдать ИИ на оформление, а потом локально вернуть
исходный текст.

## Как это работает

1. **Зашифровать.** Откройте .pptx. Отметьте, что скрыть: галочкой целый абзац, выделением кусок
   абзаца или поиском «зашифровать все вхождения». Программа сохранит `имя.enc.pptx` и покажет
   **ключ** — строку вида `SHIFR1-XXXXXX-…`. Сохраните его сами: программа ключ нигде не хранит.
2. **Отдать ИИ** файл `имя.enc.pptx` и попросить менять **только оформление**: шрифты, цвета,
   расположение, размеры окон. Текст при этом не трогать.
3. **Расшифровать.** Откройте полученный от ИИ файл, вставьте ключ, сохраните `имя.dec.pptx`.

Оригинал не изменяется никогда.

### Как выглядит зашифрованный текст

`Иванов Иван` превращается в `⟦3C8A·Дбщицд Ажфя⟧`:

- длина, пробелы, пунктуация, регистр, а также позиции букв и цифр сохраняются, так что окна
  на слайде остаются того же размера;
- в скобках `⟦…⟧` номер фрагмента и контрольная сумма: по ним программа находит фрагмент,
  куда бы ИИ его ни передвинул, и замечает, если его исказили.

Если ИИ изменит оформление внутри фрагмента (например, сделает часть слов жирными), после
расшифровки оно сохранится.

### Что ещё делает программа при шифровании

- удаляет комментарии, миниатюру файла и свойства документа (автор, компания, названия слайдов);
- по умолчанию удаляет заметки докладчика и замещающий текст (alt) объектов;
- удаляет из диаграмм встроенные таблицы Excel: в них лежит исходный текст подписей;
- предупреждает о том, что не шифруется: картинки, OLE-объекты, адреса гиперссылок,
  числа в диаграммах, вторая копия текста SmartArt.

### Резервная копия (.shifr)

Её можно включить галочкой. Это зашифрованный тем же ключом файл со всеми исходными
фрагментами. Если ИИ испортит или удалит метки, программа восстановит текст из копии.
Без копии испорченные фрагменты показываются в отчёте с примерной расшифровкой и
кнопкой «Скопировать».

## Безопасность

- Шифрование: ключевой поток AES-256-CTR, отдельный для каждого фрагмента, и посимвольная
  замена внутри алфавита. Ключевые подпрограммы выводятся из 256-битного ключа через HKDF-SHA256.
  Целостность каждого фрагмента: HMAC-SHA256, усечённый до 15 бит. Резервная копия: AES-256-GCM.
- Для каждой презентации генерируется новый ключ.
- **Что видит ИИ:** длину и «форму» скрытых фрагментов (сколько слов, где цифры и заглавные),
  число фрагментов и весь текст, который вы не отметили.
- Программа работает полностью офлайн и не обращается к сети.
- Это не сертифицированное СКЗИ.

## Запуск

Готовые файлы лежат в разделе **Releases** репозитория (собираются GitHub Actions):

- Windows: `shifr.exe`, запускается без установки;
- Alt Linux: `shifr-linux-x86_64`. Сделайте его исполняемым (`chmod +x shifr-linux-x86_64`) и
  запустите. Если `/tmp` смонтирован с `noexec`, запускайте так:
  `mkdir -p ~/.cache/shifr && TMPDIR=~/.cache/shifr ./shifr-linux-x86_64`.
